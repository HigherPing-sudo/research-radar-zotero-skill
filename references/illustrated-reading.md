# 图文精读与增量更新

用于新精读、已有精读补图和细化讲解。在用户模板内组织阅读，不另建一份重复笔记。默认中文，技术术语保留原文，先讲清机制，再给数学和证据；篇幅随问题复杂度增加，详细体现在解释而非重复摘要。

## 从真实来源选图

完成正文阅读后，选择承载主要解释与结论的原图：方法/光路/网络结构、关键受控比较、泛化或重复性，以及能揭示失败的案例。选择由证据决定，不为凑数量搬运全部图片。图表证据表继续覆盖阅读范围内的主要图表；对未嵌入但相关的图保留页码与分析。

优先从已核验的本地 PDF 渲染完整图区域；这能同时保留矢量线条、文字、位图与分面。只提取嵌入 image 对象可能漏掉坐标或整幅矢量图。裁去排版留白即可，保留坐标、单位、图例、颜色条、误差条、子图标记和断轴；阅读关键小图时可另加清楚标明范围的放大图。

图片保存到项目的 `Note/Attachments/<稳定论文标识>/`（以实际 `note_directory` 为准），文件名用图号；相同图号的 SI 与正文使用不同前缀。使用 Obsidian 库相对嵌入，如 `![[Research Radar/Note/Attachments/paper-id/Figure1.png|760]]`，按 `obsidian_project_path` 调整前缀。每图标原图号、PDF 页序及原文图页或 DOI 入口；印刷页码另列，保留实际 PDF 版本。来源清单可用 PDF 与图片哈希、裁切区域和页码记录。

提取后实际查看图片，逐一检查对应图号、裁切完整性、文字可读性和嵌入路径；文件存在不等于呈现合格。已有带注释图片先保留，新增版本使用另一文件名。找不到图或全文时，如实说明来源受限与影响，不把自行重绘的示意图说成原文证据。额外 SI 仍按用户已确认的范围处理，配图不自动授权扩大下载或阅读。

## 图旁解释怎样写

将方法图放在方法部分、关键实验图放在对应结果附近，而非只放末尾图库。每幅图的讲解让读者能独立回答：

- **怎么看：** 从哪一格/哪条箭头开始，横纵轴、颜色、归一化、误差条或分母是什么；比较时哪些条件相同。
- **发生了什么：** 用具体过程解释曲线/模块为何变化，指出关键区域与失败情形。
- **能带走什么：** 图直接支持的结论、尚未排除的解释，以及对用户项目的迁移条件。

不要仅翻译图注。先用一句易懂的话建立直觉，再给必要术语与细节。例如讲开放集时，先说明系统允许拒绝不认识的输入，再按混淆矩阵解释未知误接受和已知误拒的不同分母。类比只帮助解释机制，不能代替物理模型或扩大证据。

关键公式先说明用途，再列符号、形状/维度、单位、假设与来源；用小数值算完，并明确哪些是教学构造。公式有原文歧义时保留并说明实现待核查。把方法的输入、输出、中间步骤、训练与推理或校准与验证区分开，避免读者只记住模型名称。

结果同时记录数值、单位、分母和评价条件。对高 R²、平滑曲线或高相似度，说明它没有自动证明什么；区分相关与因果、合成叠加与独立制样、内部选择与冻结终测、模型计数与绝对物理量。用用户领域的具体例子解释迁移，且将建议与论文已做实验明确区分。

## 已有笔记补图或扩写

修改前读取完整笔记、当前 frontmatter、个人批注和复选框，记录要保留的内容与图片。优先在对应章节增补原图和教学说明；需要改写时先比对原文，不丢弃用户写在其他章节的文字。`template/status`、来源身份、原阅读日期、评论判断和已填写的下一步保持用户现状；更新日期如有需要另记，不把 AI 修改当成用户已读确认。

复查没有重复笔记、重复嵌图、失效链接或跨论文图片。核对原有正文/批注保留、索引仍只计一次，以及 `template` 勾选与评论同步继续正常。公开 skill 只包含通用说明、模板、提取脚本与测试；用户 PDF、图片、笔记和本机来源清单留在项目。

## 可选图片提取助手

脚本依赖 **PyMuPDF**，按需安装 `python -m pip install PyMuPDF`；其他原有只读脚本仍只需标准库。先查看 PDF 页并选择区域，将同一 PDF 的所需图写入 regions JSON，坐标为 PyMuPDF 使用的左上角起点 PDF points，页码从 1 开始：

```json
[
  {"id": "Figure1", "page": 3, "clip": [45, 55, 550, 330]},
  {"id": "Figure4", "page": 7, "clip": [50, 60, 540, 480]}
]
```

在 skill 目录运行：

```text
python scripts/extract_paper_figures.py --pdf "正文.pdf" --regions "regions.json" --output-dir "项目/Note/Attachments/paper-id" --dpi 216
```

区域由 agent 看图后明确指定，示例坐标不是通用裁切值。助手生成 PNG 和 `figures.json`（源 PDF 哈希、页序、区域、分辨率与图像哈希），不会自动决定图号、读图含义或修改笔记。相同输入重跑不改既有文件；图片或来源清单已不同则停止，先检查用户修改或选择新的输出目录。生成后仍须完成上面的视觉检查与说明。
